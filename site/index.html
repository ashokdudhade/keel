Same MCP tools and the same index. Absolute path to the keel binary; KEEL_INDEX_DB is optional (cwd walk-up → daemon registry → fallback). After upgrades, refresh MCP so tools pick up module and trust metadata.

Why Keel

The spine under the agent

Agents infer from text. Keel answers from an indexed graph of your repository.

  • 01

    Deterministic

    Same repo state produces the same answers. No embeddings, no semantic drift, no cloud index.

  • 02

    Local-first

    Tree-sitter parsing and SQLite on your machine. Your source never leaves your environment.

  • 03

    Agent-native

    MCP tools for definition, references, callers, implementations, dependencies, and impact.

Capabilities

What the agent can call

Seven structural tools. Prefer Keel for named symbols; fall back to text search for regex. Responses include confidence and notes. Optional module (or qualified names like crate::mcp::serve) disambiguates overloads. Non-empty impact is a candidate blast radius—verify before edits.

Get started

Install, then wire your agent

macOS with Homebrew is the smoothest path. Linux and WSL use the curl installer, which detects OS/arch and puts keel on PATH.

Homebrew
brew tap ashokdudhade/keel https://github.com/ashokdudhade/keel
brew install ashokdudhade/keel/keel
brew services start keel
cd /path/to/project && keel start
curl
curl -fsSL https://raw.githubusercontent.com/ashokdudhade/keel/main/install.sh | sh
# open a new terminal, then:
keel daemon
cd /path/to/project && keel start

After keel start, wire MCP with an absolute path to keel. KEEL_INDEX_DB is optional. Native Windows is not supported — use WSL2.

Upgrade

Already installed?

Upgrade the binary, restart the daemon, refresh MCP, and re-index when release notes say so (required after 1.2+ module-identity / trust changes if the index is old).

Homebrew
brew update
brew upgrade ashokdudhade/keel/keel
brew services restart keel
cd /path/to/project && rm -rf .keel && keel start
curl
curl -fsSL https://raw.githubusercontent.com/ashokdudhade/keel/main/install.sh | sh
# restart keel daemon if running, then:
cd /path/to/project && rm -rf .keel && keel start
