1. Implementation review summary

Full correctness review of indexing, SQLite, resolution, deps/impact, language plugins, API, MCP, and CLI.

Strengths

  • Incremental indexing with hash skip + row clear + stale delete in one transaction.
  • Deterministic ORDER BY on queries; MCP/HTTP keep stdout/response hygiene.
  • Rust extraction quality (module paths, use/imports, impls) is the strongest language path.
  • Schema migrations and re-index idempotency covered by tests.

Critical issues found (then fixed)

  • TS module_path collapsed all files to "module" — broke cross-file resolution.
  • Impact/deps over-reported via bare-name / tier-3 path-order fallback.
  • Absolute vs relative path keys broke incremental stability.
  • One bad file failed the entire index; API dropped requests on handler errors; no WAL/busy timeout.

5. Cursor integration how-to

To use SecondBrain as a Cursor MCP server for a project:

{
  "mcpServers": {
    "secondbrain": {
      "command": "/Users/ashokdudhade/os/second-brain/reports/sb",
      "args": ["mcp"],
      "cwd": "/ABS/PATH/TO/PROJECT"
    }
  }
}
  1. Build release: cd second_brain && cargo build --release
  2. In the target project: sb index . (creates .secondbrain/index.db)
  3. Point Cursor MCP cwd at that project; restart MCP
  4. Ask the agent to call tools: definition, references, callers, implementations, dependencies, impact, index
  5. Optional: sb serve --port 7645 for HTTP GET /symbol/{name}

Automated MCP framing check in this run: PASS (tools/list + definition).
